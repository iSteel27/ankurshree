# Contributing to AnkurShree

Thank you for your interest in contributing to AnkurShree! 🌱

## How to Contribute

### 🐛 Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Clearly describe the problem and steps to reproduce
- Include screenshots if applicable

### 💻 Code Contributions
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Commit your changes (`git commit -m 'Add: brief description'`)
4. Push to your branch (`git push origin feature/your-feature-name`)
5. Open a Pull Request

### 📝 Commit Message Convention
```
Add: new feature description
Fix: bug fix description
Update: changes to existing feature
Docs: documentation changes
Style: formatting, no code change
Refactor: code restructuring
Test: adding tests
```

### 🧑‍🏫 Non-Code Contributions
You don't need to code to contribute! We need help with:
- **Field research** — ground-level insights from Indian cities and villages
- **Legal guidance** — NGO registration, DPDP compliance, FCRA process
- **Content writing** — skill curriculum in simple Hindi and regional languages
- **Design** — UI/UX for first-time smartphone users
- **Translations** — making the app accessible in more Indian languages
- **Mentorship** — volunteering to teach a skill to one woman

## Code of Conduct

### Our Pledge
AnkurShree is a platform built to protect and empower vulnerable women. Every contributor must uphold the highest standards of respect, safety, and dignity.

### Standards
- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the community and mission
- Show empathy towards other community members

### Unacceptable Behavior
- Harassment, trolling, or personal attacks of any kind
- Sexist, racist, casteist, or discriminatory language
- Publishing others' private information without consent
- Any conduct that could compromise beneficiary safety or privacy
- Using project resources for personal gain at the expense of the mission

### Enforcement
Violations will be reviewed by project maintainers. Serious or repeated violations will result in permanent ban from the project.

## Questions?

Open a Discussion on GitHub or reach out to the maintainers.
