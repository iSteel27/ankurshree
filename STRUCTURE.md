# AnkurShree — Project Structure

This document explains the repository layout.

```
ankurshree/
│
├── README.md                 # Main project page (you are here)
├── CONTRIBUTING.md           # How to contribute
├── LICENSE                   # AGPL-3.0 License
├── STRUCTURE.md              # This file — repo layout guide
│
├── docs/                     # Documentation
│   ├── vision.md             # Detailed vision & philosophy
│   ├── pillars.md            # Deep dive into the 6 pillars
│   ├── revenue-model.md      # Complete revenue breakdown
│   ├── legal-compliance.md   # Legal requirements & checklist
│   ├── privacy-framework.md  # DPDP Act compliance & data architecture
│   └── assets/               # Images, logos, diagrams
│       └── logo-placeholder.png
│
├── app/                      # Mobile application (future)
│   ├── android/
│   └── ios/
│
├── backend/                  # Server & API (future)
│   ├── api/
│   └── database/
│
├── curriculum/               # Skill training content & guidelines
│   ├── foundation/           # Life skills modules
│   ├── vocational/           # Income-generating skill guides
│   └── entrepreneurship/     # Business startup guides
│
└── field-ops/                # Field operations playbooks
    ├── mentor-onboarding.md  # How to recruit & verify mentors
    ├── learner-onboarding.md # How to onboard learners
    ├── shg-integration.md    # Working with Self-Help Groups
    └── pilot-district-plan.md# District-level launch playbook
```

## What Goes Where

| I want to... | Look in... |
|---|---|
| Understand the project | `README.md` |
| Read about the vision in depth | `docs/vision.md` |
| Understand legal requirements | `docs/legal-compliance.md` |
| Contribute code | `app/` or `backend/` |
| Write skill training content | `curriculum/` |
| Plan field operations | `field-ops/` |
| Add images or branding assets | `docs/assets/` |
